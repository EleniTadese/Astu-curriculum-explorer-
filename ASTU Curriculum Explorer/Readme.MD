# ASTU Curriculum Explorer

## Project Description

Welcome to the **ASTU Curriculum Explorer**, a user-friendly web application designed to simplify the process of exploring academic programs at Adama Science and Technology University (ASTU). This application allows students to navigate through various academic streams, departments, and sub-departments, helping them find the information they need for their academic journey.

### Features

- **Interactive Navigation:** Users can seamlessly navigate between different pages, including Welcome, About, Stream Selection, Department Selection, and Sub-Department Selection.
- **Stream Options:** Choose between Engineering and Applied Science streams.
- **Department Listings:** View available departments within each stream.
- **User-Friendly Interface:** Designed with a clean and intuitive layout for ease of use.

### Technologies Used

- HTML
- CSS
- JavaScript
